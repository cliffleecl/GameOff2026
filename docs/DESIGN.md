# Brain Shift 設計文件

> 版本：v0.4（跑酷版）｜平台：H5（itch.io HTML 模式、GitHub Pages）｜不移植 Unity
>
> 數值以 `src/config.js` 為準。這份文件記的是「為什麼這樣設計」；改了數值或規則，請同步更新這裡。

## 1. 一句話

**你會翻牆，牠們會學。** 你是跑酷專家，殺不死殭屍，只能甩掉；你用哪一招，屍群就進化出破解那一招的類型。

主題「Shift」體現在兩邊：玩家要不斷換位置、換手法；屍群的族群組成也隨玩家的打法不斷偏移。

## 2. 核心循環

1. 開場地圖上只有少數**遊蕩殭屍**，不會主動追你。
2. 你去撿**材料箱**（金色），材料用來做道具。
3. 被遊蕩殭屍看到後，屍群才開始派**追兵**。
4. 你用翻越、障礙、陷阱、誘餌甩掉追兵。每一次成功，都會累積成屍群的**學習事件**。
5. 學習事件累積夠了，**屍群進化**：族群比例改變，也更認得陷阱、更能識破誘餌。
6. 集滿 6 個**零件**（藍色光柱）→ 回無線電呼叫救援 → 撐 30 秒 → 衝回無線電上直升機。

一局約 3–4 分鐘，進化約 2–10 次（看打法）。

## 3. 玩家

| 項目 | 設定 |
|---|---|
| 生命 | 70（原本 100，真人試玩覺得太耐打）。血條顯示在角色腳下，不顯示數字。 |
| 速度 | 3.0 格／秒 |
| 翻越 | 可以翻過場景矮牆和自己放的障礙。翻越時速度 ×0.8，落地後 1.5 秒內 ×1.3（3.9），加速時角色身邊有速度線、鏡頭視角稍微拉寬；起跳和落地揚起塵土。 |
| 站在牆上 | **不是安全區**。站在矮牆／障礙上時，旁邊的殭屍攻擊距離 +0.35（`perchReach`），翻不過的殭屍會走到牆邊來抓你。 |
| 回血 | 3 秒沒受傷、且 6 格內沒有殭屍時，每秒回 5。 |
| 攻擊 | **沒有**。殭屍殺不死。 |
| 推開 | 已關閉（`CFG.PLAYER.shoveEnabled = false`）。程式還在，改成 `true` 就恢復。 |

**為什麼沒有攻擊**：一路從「揮劍」→「盾推（不傷害）」→「連推開都關掉」。只要玩家能自己處理貼身的殭屍，被追就不可怕，逃跑路線被學走也不痛，道具就變成輔助。

## 4. 道具（都用材料做）

三種道具**價格一樣**（`CFG.ITEM_COST = 8`），按鈕上不顯示價格。材料上限 64（＝8 個道具），顯示成角色血條下方的金色材料條，一格＝一個道具。**一個材料箱補一格**（`SCRAP.units = 1`），撿到時材料條閃一下，不跳文字。

| 道具 | 花費 | 放哪裡 | 效果 | 壽命 |
|---|---|---|---|---|
| 障礙（施工路障） | 8 | **正前方**，一道 3 格寬，橫擋在你面向的方向 | 你翻得過（還會加速），多數殭屍過不去。放下時跟殭屍重疊會把牠彈開並暈 1 秒。 | 被拆除殭屍拆掉為止（耐久 60） |
| 陷阱（捕獸夾） | 8 | **腳下** | 踩到的殭屍定身 1.2 秒＋減速 2 秒。你自己踩不會觸發。 | 觸發 10 次 |
| 誘餌（一塊肉） | 8 | **往前丟 5 格** | 15 秒內把 9 格內的殭屍引過去，咬到停 2 秒。遊蕩殭屍和守衛被引走後會留在那一帶。 | 15 秒 |

放置位置固定，被擋住才依序往兩側偏。

**三種道具的分工**
- 障礙：製造速度差（翻越加速）、擋住直衝的。
- 陷阱：卡住緊追在後的（近距離、硬控）。
- 誘餌：調動整群殭屍的位置（遠距離、引開守衛）。

## 5. 殭屍

殭屍殺不死。追兵跟丟你 12 秒後回到**遊蕩**狀態（留在原地附近晃），不會消失。

| 類型 | 顏色 | 速度 | 攻擊 | 強項 | 弱點 |
|---|---|---|---|---|---|
| 盲衝 | 紅 | 2.8 | 4 | 數量多 | 只照視線直衝，會卡在障礙前，看不到你就跟丟；學陷阱只學得到一半 |
| 繞路 | 黃 | 3.0 | 4 | 會尋路、從你前方包抄、預判路線、天生繞開陷阱、不太上誘餌的當 | 過不了障礙 |
| 拆除 | 紫 | 1.8 | 5 | 場上有障礙就直接去拆 | 很慢 |
| 跑酷 | 青 | 3.5 | 3 | 最快、會翻矮牆和障礙 | 不會預判、攻擊低、會踩陷阱 |

**設計原則：破解型殭屍是「不同」，不是「更強」。** 每一型都要有明確弱點，進化是在換題目，而不是單純變難。

每個新類型第一次出現時，畫面會提示牠的特性。

### 殭屍頭上的標記
- 紅色：發現你了（遊蕩或埋伏 → 追擊）。
- 黃色＋抖動：被你放的障礙卡住。
- 黃色（不抖）：認出陷阱，正在繞開。

## 6. 學習與進化

### 6.1 什麼時候進化（事件觸發）

不是固定時間。累積 **30 點學習事件**就進化一次，兩次之間至少隔 10 秒。畫面右上的「屍腦」進度條顯示目前進度。

學習事件：障礙擋住殭屍、翻越甩掉追兵、陷阱夾到、誘餌騙到、躲到廢墟後甩掉、甩掉追兵（各 1 點）、撿到零件（3 點）。

**原因**：固定時間會讓「還沒被發現的平靜期」白白進化；事件觸發讓玩家玩得越積極、屍群進化得越快，學習的因果更清楚。

### 6.2 族群進化：你做的事 → 變多的類型

| 你做的事 | 變多的類型 |
|---|---|
| 障礙擋住殭屍、放很多障礙 | 拆除 |
| 靠翻越甩掉追兵 | 跑酷 |
| 陷阱夾到殭屍、誘餌騙到殭屍、躲到廢墟後面甩掉 | 繞路 |

開場權重：盲衝 1、繞路 0.15、拆除 0.05、跑酷 0。前 45 秒只生盲衝。進化速度不固定：用得越多，偏移越快。

### 6.3 全屍群的學習（即時生效，場上所有殭屍一起變聰明）

- **陷阱**：每夾到一隻，屍群「認得陷阱」的比例 +10%，上限 85%。認得的殭屍會繞開**任何**陷阱（不是記某一格），頭上冒黃色標記。繞路型天生認得；盲衝型只算一半。
- **誘餌**：每騙到一隻，「識破誘餌」+5%，上限 80%。上鉤機率 = 85% ×（1 − 識破程度）；繞路型再 ×0.3。

### 6.4 行為學習

- **熱點埋伏**：記住你常待、常撿東西的區域，之後有殭屍先去那一帶等你；跟丟你的殭屍也會往熱點晃。
- **守零件**：看過你撿零件之後，每個新零件旁邊會先有最多 2 隻守衛。
- **預判**：繞路殭屍會往你「等一下會在的位置」追。你甩掉追兵越多次，預判得越遠（上限 1.2 秒）；還會依你被追時習慣往左或往右拐來偏移。
- **屍潮方向**：從你被追時習慣逃跑的方向來。

### 6.5 進化報告

左上角小卡片，每行一個重點、最多 4 行，5 秒後消失。固定用清楚的句子（`reportFade = false`；曾經做過「越講越模糊」，玩起來不好，預設關掉）。

## 7. 地圖與節奏

- 40×30 格，每局隨機產生。**廢墟**（高、擋路也擋視線）、**矮牆**（低、可翻越、不擋視線，約 20 多格）。保證不翻牆也能走到所有空地。
- 材料箱 12 個，一箱補材料條一格；撿走 5 秒後在別處重生。
- 零件一次一個，出現在離你 13 格以上的地方，一半機率挑你很少去的區域。零件是**通訊器的六個部分**：天線、電池、電路板、喇叭、話筒、調頻旋鈕（依序出現）；撿到的會裝到中央的無線電上，HUD 的對應圖示也會亮起來。
- 開場 6 隻遊蕩殭屍（離無線電 12 格以上，視野 5 格）。**被牠們看到之前不會有追兵。**
- 被發現後：追兵持續生成，同時追擊的上限隨時間放寬；約每 80 秒一次屍潮（會先預警方向）。
- 撤離三階段：回無線電呼叫 → 撐 30 秒（去哪都行，殭屍變多）→ 直升機降落，衝回無線電。最後 10 秒直升機從遠處飛進來，降在無線電旁的停機坪；你上機後直升機爬升飛走，再出結算畫面。
- 氛圍：**夜晚、很暗，主要靠手電筒找路**。手電筒從角色往面向的方向照（廢墟會擋光），光圈從腳前開始；角色身上有一圈暖光（放在鏡頭那一側，照亮看得到的那一面），背後貼身的殭屍也看得到；殭屍的發光眼睛在黑暗裡最先被看到。遠處沒入霧裡、四周暈影、飄動的霧團。無線電旁有**營火**（真光源＋火星＋地面光暈），標題畫面和遊戲中一眼就找得到據點。直升機探照燈用地面發光貼圖（不是真光源，省效能）。
- 美術：全部由程式產生的低面數模型（`src/models.js`），不用外部模型檔。
  - 四種殭屍靠**輪廓**區分，不只靠顏色；外型暗示弱點：盲衝＝駝背、雙手前伸；繞路＝雨衣兜帽＋大背包＋手電筒；拆除＝壯、安全帽、扛鐵鎚；跑酷＝瘦長、壓低身體、頭帶。眼睛會發光，顏色依類型不同，在霧裡也看得到。
  - 玩家是暖色（橘色帽 T），殭屍都是綠皮膚＋冷色眼睛，避免撞色（拆除殭屍的安全帽因此用白色，不用橘色）。
  - 廢墟＝水泥塊（完整／崩塌／露鋼筋三種），矮牆＝沙包（一看就知道翻得過去），障礙＝施工路障，陷阱＝捕獸夾。
  - 地板每局畫一張整圖，像自然的城市廢墟、**沒有格線**：大片明暗變化的柏油、碎掉的水泥板（接縫歪斜）、褪色的道路與斑馬線、泥土、水窪、會分岔的裂縫、人孔蓋、雜草，廢墟腳邊有灰塵和接觸陰影，無線電旁有直升機停機坪。
  - 跑酷殭屍外觀縮小（`scale 0.75`），碰撞大小不變。

## 8. 操作

| 平台 | 移動 | 道具 | 其他 |
|---|---|---|---|
| 電腦 | WASD／方向鍵，或滑鼠點地面 | 1 障礙、2 陷阱、3 誘餌 | F 加速、H 記憶圖、R 連按兩次重新開始（畫面上沒有這三個按鈕） |
| 手機（橫向） | 左半邊畫面任意處按住＝浮動虛擬搖桿 | 右下角三顆圓鈕 | 直向時顯示「請轉成橫向」 |

「記憶」圖層：紫＝你常去的地方（屍群的埋伏熱點）、橘＝殭屍被你的障礙卡住的地方。

**畫面流程**：全螢幕標題（Logo、開始遊戲、如何遊玩、語言）→ 開場運鏡（鏡頭從標題鏡位滑到遊玩鏡位，約 1.6 秒）→ 遊戲 → 結算（大數字：存活時間、零件、屍群進化、使用道具、甩掉追兵，以及最後的族群比例）→ 再玩一次（直接切，不運鏡）／回標題。
**如何遊玩**：全畫面分成 6 頁（目標、只能逃、道具、屍群會學、四種殭屍、操作），每頁一張示意圖（`src/howto.js`，內嵌 SVG）＋短文字。上方分頁籤、下方上一頁／下一頁，鍵盤 ←→、手機左右滑；最後一頁的「下一頁」是「開始遊戲」。
**HUD**：上方置中三格、大小一樣、只用圖示：零件（六個通訊器零件圖示）、時間、屍腦進度。血量和材料跟在角色腳下。電腦版的 HUD、道具按鈕、血條、小地圖都比手機大（1080p 以上再大一級）。
**文字提示**只留重要的：開局目標、被發現、新類型出現、屍潮、撤離、零件。陷阱壞掉、障礙被拆、撿到材料、障礙撞暈殭屍都不跳文字（看場景就知道）。
**語言**：英文、繁體中文、簡體中文（主要客群是英文）。第一次開啟依瀏覽器語言決定，之後記住玩家的選擇。所有文字在 `src/i18n.js`。

## 9. 設計決定紀錄（依時間）

| 決定 | 原因 |
|---|---|
| 從 2D 塔防改成 3D 俯瞰、玩家就是核心 | 「被會學習的東西追著跑」比「重蓋防線」更貼 Shift |
| 拿掉波次、擊殺獎勵、被動收入，改成撿資源 | 原本蹲在原地蓋塔繞圈就能贏；要給玩家離開安全區的理由 |
| 拿掉機槍塔，改成跑酷＋非致命道具 | 塔讓玩家不必移動；非致命讓「甩掉」成為唯一解 |
| 四種殭屍對應四種破解方式 | 讓進化看得懂：你用什麼，牠們就長出什麼 |
| 追兵比玩家快（繞路 3.0、跑酷 3.5） | 不能只靠走位甩掉，必須用道具和地形 |
| 翻越後短暫加速、障礙放前方 | 讓障礙同時是擋路工具和加速踏板；跑酷的衝勁 |
| 陷阱、誘餌的學習全屍群即時生效 | 「下一代才學會」玩家感覺不到 |
| 殭屍發現陷阱只冒標記、不停頓 | 停頓反而讓陷阱效果變好 |
| 推開機制關掉 | 太強，被包圍太容易脫身 |
| 進化改成事件觸發 | 見 6.1 |
| 血條移到角色腳下 | 平常不會去看畫面上方 |
| 手機改橫向＋虛擬搖桿 | 直向點地面很難玩 |
| 不移植 Unity，專心做 H5 | 直接上 itch.io／GitHub Pages |
| 三種道具統一價格 8、材料上限 64 | 玩家只要記一個數字。試過統一成 10：模擬「用道具」平均存活 140→128 秒、勝率 3%→1%（主要是障礙漲價）；統一成 8 回到 137 秒，陷阱、誘餌還變便宜，符合「讓道具更有價值」。上限是為了能畫成一條材料條，對數據影響很小 |
| 畫面變暗、改成手電筒 | 「拿手電筒在廢墟裡找零件」的氣氛；殭屍的發光眼睛變成第一個看到的訊號。**可能提高難度**（背後、遠處較難看清楚），要真人試玩確認 |
| 即時光源只留 4 個，其他用發光貼圖假裝；手機解析度上限 1.25 倍 | 實測幀時間幾乎跟像素數成正比（解析度 1 倍比 2 倍快約 40%），陰影、光源的影響小很多 |
| 無線電旁加營火（第 5 個即時光源）、角色暖光加強、環境光 0.24→0.34 | 真人試玩：整體太暗、標題和遊戲中看不清楚據點、手電筒光圈離角色太遠。營火同時是「據點」的視覺記號 |
| 材料箱一箱＝材料條一格（原本 6–16，越遠越多） | 真人試玩要求「撿一個補一格」，好懂。平均收入變少：模擬「用道具」存活 137→124 秒（同時含站牆修正） |
| 生命 100→70 | 真人試玩覺得太耐打。模擬 60 局：用道具存活 124→103–116 秒（兩次跑的差距），不用道具 104→76 秒；60 會再掉約 15 秒，先取 70 |
| 站在矮牆／障礙上不再是安全區 | 原本翻不過的殭屍走不到你那格就停住，玩家站在牆上什麼事都不會發生，變成「站著不動」的最佳解 |
| 加速改用速度線，塵土只在起跳／落地 | 原本的粒子看起來像揚塵，不像加速 |
| 如何遊玩改成全畫面分頁＋示意圖 | 彈窗一大段文字不好讀；原本返回鈕的文字跟底色同色（看不到） |
| 拿掉多餘的文字提示 | 陷阱壞了、取得材料這類訊息太頻繁，蓋掉真正重要的提示 |
| 移除畫面上的重置、記憶、速度按鈕 | 畫面乾淨；這三個是開發／進階功能，電腦用快捷鍵 |
| 零件改成通訊器的六個部分，撿到的裝到無線電上 | 「修好無線電」的目標更具體，HUD 用六個零件圖示表示進度 |
| 模型用程式產生、零件合併成一個幾何（頂點上色），殭屍用腳下圓形陰影而不是真陰影 | 風格統一、不用載入檔案；手機的瓶頸是 draw call，一隻殭屍從約 9 次降到 5 次、且不進陰影計算。想換成特定美術風格時，再改讀 GLB（低面數、有骨架與待機／跑／攻擊動作），程式模型留作備援 |
| 加入自動測試：Vitest（邏輯）＋ Playwright E2E（打包後在電腦與手機橫向跑），push 時在 GitHub Actions 跑 | 本機跑 E2E 很吃 CPU；遠端跑還能順便驗證相對路徑與模擬玩家有沒有卡死 |

## 10. 已知問題與待驗證

1. **難度偏高，而且只有模擬數據**。關掉推開之後，模擬玩家幾乎贏不了（平均撐約 130–160 秒）。真人已通關過（推開還在的版本），關掉推開後還沒有真人數據。可調的補償：翻越加速時間、回血、開場材料。
2. **障礙值不值得放，模擬測不準**。模擬玩家只會在逃跑時往前丟，不會用在窄路或保護退路，所以「用道具 vs 不用道具」的勝率差只能當相對參考。
3. **追兵回到遊蕩會越積越多**。4 分鐘時場上殭屍比「跟丟就消失」多約 50%。備案：遊蕩殭屍設總數上限、或遊蕩一段時間後消失。
4. **陷阱和誘餌的定位仍有點像**（都是延遲追兵）。備案：被陷阱夾住的殭屍變成路障，堵住後面的。
5. **觸控手感沒在實機驗證**：搖桿大小、死區、右手按鈕位置。
6. **效能沒在實機驗證**：陰影、霧團、最多約 40 隻殭屍。已做：手機解析度上限 1.25 倍、手機不算月光陰影、手電筒陰影 512、殭屍合併幾何＋圓形陰影、即時光源 5 個（加了營火；手機太慢的話可以先拿掉營火光源，只留發光貼圖）。改成逐像素打光（Phong）後，軟體繪圖下幀時間比上一版多，主要成本是像素數；仍需實機確認。
7. **變暗之後的難度**：手電筒照不到的地方（背後、遠處）比較難看清楚殭屍，只能靠發光眼睛和小地圖。要真人試玩確認是否太難；可調的地方：`view.js` 的環境光、月光強度、手電筒角度與距離。
8. **手機上沒辦法中途重新開始或回標題**（重置按鈕已移除，只有電腦有 R 鍵）。如果需要，建議加一個暫停按鈕（暫停選單裡放重新開始、回標題）。

## 11. 版本沿革

- **v1** 2D 塔防原型：固定核心、8 波、死亡熱圖與突破記憶。
- **v2** 3D 波次版：玩家即核心、邊逃邊蓋、盾推、拆塔殭屍。

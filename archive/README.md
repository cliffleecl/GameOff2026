# 舊版本存檔

這些是拆成正式專案之前的單檔版本，只留著對照設計演變，**不要在這裡改東西**。直接用瀏覽器開啟就能玩（v2–v4 需要網路載入 Three.js）。

| 檔案 | 內容 |
|---|---|
| `v1_2d_tower_defense.html` | 2D 塔防：固定核心、建造階段、8 波殭屍、死亡熱圖 |
| `v2_3d_waves.html` | 3D 俯瞰：玩家就是核心、邊逃邊蓋、波次制、盾推、機槍塔 |
| `v3_scavenge.html` | 搜刮版：大地圖、撿物資、無波次、屍腦更新、無線電撤離 |
| `v4_parkour_single_file.html` | 跑酷版拆檔前的最後一個單檔快照（`src/` 就是從這個檔拆出來的） |
